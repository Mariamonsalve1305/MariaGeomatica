# 📈 Urban Mobility & Economic Indicators: A Data-Driven Analysis - Proyect 1

## 🎯 Project Executive Summary
This project analyzes the intricate relationship between urban mobility patterns and key economic indicators in Latinoamerica. Using Python-based data science workflows, I integrate, clean, and standardize diverse datasets to uncover insights that inform sustainable land management and data-driven urban planning. The core of this analysis lies at the intersection of spatial dynamics and economic vitality, leveraging datasets to tell the story of how a city moves and prospers.

## 🚀 Key Objectives
* **Data Integration & Cleaning:** Consolidate disparate datasets from mobility and economic sources, implementing robust cleaning, normalization, and standardization techniques to ensure data integrity for analysis.
* **Standardize Spatial Coordinates:** Convert all geographic data into a unified coordinate system (e.g., EPSG:4326) to accurately align mobility layers with land use and economic zones.
* **Correlation & Modeling:** Investigate statistical relationships and apply to quantify the impact of mobility on economic prosperity metrics.
* **Actionable Data Visualization:** Create compelling, interactive visualizations and map layers using Power BI and Python libraries to effectively communicate complex data insights for decision-making.
