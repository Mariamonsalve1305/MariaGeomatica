Movilidad Urbana e Indicadores Económicos: Un Análisis Basado en Datos Urban Mobility & Economic Indicators: A Data-Driven Analysis

Este proyecto analiza la compleja relación entre los patrones de movilidad urbana y los indicadores económicos clave en Latinoamérica. Mediante flujos de trabajo basados en Python, integro, limpio y estandarizo conjuntos de datos diversos para obtener información que orienta la gestión territorial sostenible y la planificación urbana inteligente. This project analyzes the intricate relationship between urban mobility patterns and key economic indicators in Latin America. Using Python-based data science workflows, I integrate, clean, and standardize diverse datasets to uncover insights that inform sustainable land management and data-driven urban planning.

Proyecto RappiPlus: de Datos a Decisiones de Negocio RappiPlus Project: From Data to Business Decisions

El objetivo principal de este proyecto es evaluar el desempeño del servicio RappiPlus para respaldar decisiones de negocio basadas en datos. A través de un enfoque analítico, el proyecto sigue una lógica clara y progresiva para comprender la rentabilidad y el comportamiento de los usuarios. Proyecto final del Bootcamp de Análisis de Datos en Tripleten. The main objective of this project is to evaluate the performance of the RappiPlus service to support data-driven business decisions. Through an analytical approach, the project follows a clear and progressive logic to understand profitability and user behavior. Final project for the Tripleten Data Analysis Bootcamp.
